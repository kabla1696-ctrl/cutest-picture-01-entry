A baby panda sitting in a teacup: a big round face with glossy eyes and pink blush, little paws gripping the rim of a flower-patterned blue cup, steam curling up, a tiny flower on one ear, on a soft mint polka-dot background. Drawn by a deterministic Python program (Pillow + numpy) and written out as a 1024×1024 PNG.

## Run it

```sh
python3 main.py
```

`main.py` is standard library only and writes the artwork to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). The image itself lives in the repo as base64 in `art.b64`. To regenerate the artwork from scratch:

```sh
python3 draw.py
```
